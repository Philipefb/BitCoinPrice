## BitCoinPrice

Aplicativo desenvolvido para mostrar as informações do preço do bitcoin utilizando MVMM e Compose com testes unitários

## Tecnologias

- Kotlin
- Room Database
- Arquitetura MVVM
- ViewModel
- Testes Unitários
- Requisição de API
